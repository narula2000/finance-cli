# Finance CLI

A fast personal finance manager built with C++20, CLI11, SQLite and SQLiteCpp.

Manage your finances directly from the terminal.

## Features

- 💰 Track income and expenses
- 🧾 Manage financial transactions
- 🏦 Manage accounts
- 📅 View transaction history
- 📈 Financial summaries and statistics
- 💾 Local SQLite database
- 🚀 Lightweight and fast
- ⚠️ Strict compiler warnings

## Tech Stack

- **C++20** — Core application
- **CLI11** — Command-line argument parsing
- **SQLite** — Local data storage
- **SQLiteCpp** — SQLite wrapper for clean usage
- **CMake** — Build system

## Requirements

- C++20-compatible compiler
- CMake 3.20+
- Git

## Building

1. Clone the repository:

   ```sh
   git clone https://github.com/narula2000/finance-cli.git
   cd finance-cli
   ```

2. Configure the project:

   ```sh
   cmake -S . -B build
   ```

3. Build:

   ```sh
   cmake --build build
   ```

4. Run:

   ```sh
   ./build/finance-cli
   ```

5. Show CLI options:

   ```sh
   ./build/finance-cli --help
   ```

## Compiler Warnings

The project is built with strict compiler warnings:

- `-Wall`
- `-Wextra`
- `-Wpedantic`
- `-Werror`

`compile_commands.json` is also generated automatically by CMake.

## Data Storage

Finance data is stored locally using SQLite.

No external service or account is required. Your financial data stays on your machine.
